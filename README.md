# 🛍️ Product Showcase

A simple web application that dynamically loads product data from a JSON file and renders it using **Handlebars.js** templates.  
This project demonstrates key front-end development skills such as **HTML, CSS, JavaScript, JSON handling, and templating**, similar to what’s used in B2C e-commerce platforms.

---

## 🚀 Features
- Loads product data from a local `products.json` file  
- Uses **Handlebars.js** for templating and dynamic HTML generation  
- Displays responsive product cards with images, titles, categories, and prices  
- Clean, modern UI styled with HTML5 and CSS3  
- Demonstrates API-style JSON data handling and templating concepts

---

## 🧠 Technologies Used
- **HTML5** – structure and markup  
- **CSS3** – styling and layout  
- **JavaScript (ES6)** – logic and data fetching  
- **Handlebars.js** – templating engine  
- **JSON** – data format for dynamic content  

---

## 📂 Project Structure
product-showcase/
│
├── index.html # Main web page
├── style.css # Styling for the UI
├── script.js # JavaScript for data loading and rendering
└── products.json # Product data file

## ⚙️ How to Run Locally
1. **Download or clone** this repository  
2. Open the project folder  
3. Simply open `index.html` in your browser  
   - No server setup is needed (uses static JSON file)
4. The page will automatically load and display product data
