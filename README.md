# 🛍️ Product Showcase

A simple web application that dynamically loads product data from a JSON file and renders it using **Handlebars.js** templates.  
This project demonstrates key front-end development skills such as **HTML, CSS, JavaScript, JSON handling, and templating**, similar to what’s used in B2C e-commerce platforms like MacKenzie-Childs.

---

## 🚀 Features
- Loads product data from a local `products.json` file  
- Uses **Handlebars.js** for templating and dynamic HTML generation  
- Displays responsive product cards with images, titles, categories, and prices  
- Clean, modern UI styled with HTML5 and CSS3  
- Demonstrates API-style JSON data handling and templating concepts

---

## 🧠 Technologies Used
- **HTML5** – structure and markup  
- **CSS3** – styling and layout  
- **JavaScript (ES6)** – logic and data fetching  
- **Handlebars.js** – templating engine  
- **JSON** – data format for dynamic content
